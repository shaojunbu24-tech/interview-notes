## 题目详解

### 1. 单链表反转

**出现**：腾讯 WXG · 飞轮数据

```java
// 迭代法
public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

### 2. 二叉排序树找第 K 大节点

**出现**：腾讯 WXG

- 不能把二叉树全量存储到另外存储空间
- 解法：中序遍历的逆序（右→根→左），维护计数器
- 时间复杂度 O(n)，空间 O(h) 递归栈

```java
int count = 0, result = -1;
public int kthLargest(TreeNode root, int k) {
    dfs(root, k);
    return result;
}
void dfs(TreeNode node, int k) {
    if (node == null || count >= k) return;
    dfs(node.right, k);      // 先右
    count++;
    if (count == k) {
        result = node.val;
        return;
    }
    dfs(node.left, k);       // 后左
}
```

### 3. 矩阵左上到右下最大路径和

**出现**：腾讯 WXG

- 每次可以向右、向下、右下移动
- DP：`dp[i][j] = max(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + grid[i][j]`

### 4. 求根节点到叶节点数字之和（LeetCode 129）

**出现**：美团

- DFS 遍历，每次 `sum = sum * 10 + node.val`
- 到叶节点时累加到总量

### 5. 合并区间（LeetCode 56）

**出现**：TapTap · 腾讯(7.21)

- 先按左端点排序
- 遍历，当前区间和结果中最后一个比较：重叠则合并，否则新增
- 边界条件需注意：`intervals.length == 0`

```java
public int[][] merge(int[][] intervals) {
    if (intervals.length == 0) return new int[0][];
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
    List<int[]> merged = new ArrayList<>();
    for (int[] interval : intervals) {
        if (merged.isEmpty() || interval[0] > merged.get(merged.size()-1)[1]) {
            merged.add(interval);
        } else {
            merged.get(merged.size()-1)[1] = 
                Math.max(merged.get(merged.size()-1)[1], interval[1]);
        }
    }
    return merged.toArray(new int[merged.size()][]);
}
```

### 6. 验证 IP 地址（LeetCode 468）

**出现**：TapTap · 腾讯(7.21)

- 注意边界：IPv4 不能有前导零、范围 0-255、只能是数字
- IPv6 可以省略前导零、1-4 位十六进制、不区分大小写
- 注意空字符串和多余的分隔符

### 7. 三数之和（LeetCode 15）

**出现**：小熊博望

- 排序 + 双指针
- 去重：`nums[i] == nums[i-1]` 跳过
- 注意：排序后如果 `nums[i] > 0` 可以提前结束

### 8. 平衡二叉树判断（LeetCode 110）

**出现**：Meshy

- 自底向上（递归返回高度，-1 表示不平衡）
- 分析：后序遍历每个节点只访问一次（O(n)），自上而下会重复计算（O(n²)）
